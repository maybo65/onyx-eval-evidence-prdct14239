### IMPORTANT SAFETY CONSTRAINT ###
The real /home/coder/.codeartsdoer QUALIFIES as CodeArts-installed
(regular file at ~/.codeartsdoer/installers/codearts) and already carries a
guard plugin. The root install (euid=0) enumerates EVERY system user via
GetUserContextsToScan(privileged=true) and has NO per-user scoping flag, so a
root WRITE install would rewrite the real /home/coder/.codeartsdoer plugin —
which the task forbids. Therefore the root all-users path is exercised in
--dry-run ONLY (writes nothing), and the real WRITE install of the second
user's home is run directly AS that user (euid=s1testuser), which the kernel
confines to /home/s1testuser and cannot touch coder's home.
