############################ (1) uninstall codearts --help ####################
Uninstall Huawei Cloud CodeArts integration with the Onyx AI Guard.

Removes the guard plugin (~/.codeartsdoer/plugin/onyx-guard.ts and its onyx/
subdir). CodeArts's plugin/ directory is shared with the user's other plugins, so
only the Onyx-owned artifacts are removed — never the whole plugin/ dir.

When running as root (sudo), the integration is removed for all users on the
machine. Otherwise, it is removed only for the current user.

The command is idempotent - running it multiple times is safe.

Use --dry-run to preview changes without applying them.

Usage:
  onyx-scanner uninstall codearts [flags]

Flags:
      --dry-run                Show what would be changed without applying modifications
  -h, --help                   help for codearts
      --scan-api-key string    API key for post-operation scan (optional)
      --scan-endpoint string   Ingest endpoint for post-operation scan (optional)
  -v, --verbose                Enable verbose output

Global Flags:
      --dsl-enabled      Detect claude-code and the Codex CLI with the DSL envelope instead of the native Go detectors (env: ONYX_SCANNER_DSL_ENABLED; default legacy Go; an explicit flag beats the env)
      --log-dir string   Directory to store log files (default "~/.onyx/mcp-scanner/logs")
  -q, --quiet            Don't print logs to console
      --skip-certs       Skip SSL certificate verification (env: ONYX_SKIP_CERTS)
